GameSpineTool 便携版（Windows x64）

双击 GameSpineTool.exe 即可运行。.NET 10 运行时、Python 3.13、引擎脚本与
Windows App SDK 运行时都已随包提供，无需安装任何依赖。

请注意：
1. 保持整个文件夹完整，不要单独复制 exe 到别处，否则无法启动。
2. 首次运行选择游戏与输出目录，点击「开始整理」即可。
3. 运行历史保存在程序目录下的 history\ 文件夹，与 exe 放在一起。
   每份解压副本历史互相独立，不会写进输出目录或其他位置。
4. 2 倍超分组件不随包提供。首次启用超分时程序会提示下载（约 43 MB），
   下载前先各取 2 MB 实测 Gitee 镜像与 GitHub 官方两个源，选较快的那个，
   校验 SHA-256 后只保留运行所需的四个文件。
   下载过程中可随时点「取消」；中断后已下载的部分会保留，下次从断点继续。
   不下载也不影响整理主流程。

如需改用其他 Python，可设置环境变量 GST_PYTHON 指向具体的 python.exe。
